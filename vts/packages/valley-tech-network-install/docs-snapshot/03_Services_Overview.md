## Service 1: General IT Support & Troubleshooting

**What it is:** Hands-on help with computers, devices, software, and basic tech issues for homes and small businesses.

**Who it's for:** Home users, short-term rentals, small offices, or anyone frustrated with slow computers, software problems, or setup issues.

**Key benefits:**
- Quick fixes for common problems (slow PCs, WiFi issues, software installs, hardware upgrades, diagnostics)
- Help setting up or optimizing devices
- Reliable local support – no long waits or big-company runaround
- Clear explanations so you understand what’s happening

**Starter scope:**
- Computer troubleshooting and optimization
- Software installation and updates
- Basic device setup (printers, peripherals)
- Remote or on-site help as agreed

**Pricing (base):**

| Option | Price |
|--------|-------|
| Hourly | $75/hour |
| Small fixed jobs | $150–250 flat for defined tasks |

**Optional add-ons (Service 1):** billed hourly or quoted separately (e.g. data migration, multi-PC fleets).

## Service 2: Home & Small Business Network + Smart Home (Rural Focus)

**What it is:** Setup, optimization, and security for home or small-business networks — plus smart home, IoT, and media centers. Especially suited for Starlink and rural properties.

**Who it's for:** Homeowners, short-term rentals, small farms, and businesses needing reliable WiFi, guest networks, smart home setup, or media centers.

**Key benefits:**
- Better, more reliable internet performance in rural areas
- Secure and organized network setup
- Smart home device setup (Alexa, Google, Samsung, Amazon)
- Home theater / media center install for homes, rentals, and small offices
- Local expertise with Starlink and rural connectivity

**Base scope (no monitoring):**
- **VyOS (or equivalent) router appliance** provisioned in lab: WAN + **two segmented LANs** (trusted + guest/IoT), **DHCP by default**
- Onsite **plug-and-play** install (cabling + smoke test) when appliance is pre-built
- Starlink + mesh WiFi as APs / optimization (Deco or similar) as needed
- Smart home / IoT placement on guest/IoT LAN when in scope
- Home theater and media center setup when in scope
- Written handoff + cable map (port labels: WAN / LAN1 / LAN2)
- Static IPs only if requested later (manual, per client—not default)
- Optional: discovery data → **itemized quote** (automated quote tooling in progress)

**Base pricing (network job only — no monitoring):**

| Option | Price |
|--------|-------|
| Small network + smart home setup | $200–400 flat |
| Hourly troubleshooting or additions | $75/hour |

## Optional add-ons (quote separately)

Monitoring and custom router hardware are **not** included in base Service 2. Sell only when the client wants ongoing visibility or an always-on appliance.

### Add-on A — Remote Monitoring (Netdata)

| Item | Price (starter) | Notes |
|------|-----------------|--------|
| **Setup fee** | $100–150 one-time | Enroll site into your central Netdata parent; Tailscale on monitor host; test Telegram alert |
| **Monthly retainer** | $75–150/month | Alert review (Telegram); best-effort response language in agreement |

**Requires:** an always-on host (see Add-on B or client-supplied PC).  
**Alerts:** Telegram to you (Valley Tech Support).  
**Not included:** 24/7 live desk, multi-tech staffing, or guaranteed SLA beyond agreed best-effort.

### Add-on B — Custom Always-On Router Appliance

| Item | Price (starter) | Notes |
|------|-----------------|--------|
| **Custom VyOS (or similar) router build** | Quoted per hardware | x86 mini PC / approved appliance; segmentation ready |
| **Netdata child on appliance** | Usually bundled with monitoring setup | Solves “no always-on PC” when client buys Add-on A |

**Use when:** client wants monitoring/retainer but has no spare always-on computer.  
**Hardware cost:** pass-through or markup per your sourcing (document on quote).

### How the options combine

| Client choice | What you deliver | Always-on dilemma? |
|---------------|------------------|--------------------|
| **Base network only** | Service 2 job + handoff | **Moot** — no Netdata, no child host required |
| **Base + monitoring**, client has PC/NUC | Child agent on their host → your parent | Solved by their host |
| **Base + monitoring + custom router** | Appliance + Netdata child → your parent | Solved by **your** appliance (upcharge) |
| **Opt out of ongoing support, no custom router** | Base job only | **Moot** — correct |
