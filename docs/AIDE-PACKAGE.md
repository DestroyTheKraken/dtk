## What is AIDE?

**AIDE** is a private way to work:

1. **Private Cloud Platform** — your files and core tools on **your** machines, private remote access.  
2. **AI Desktop Environment** — AI helpers (the tools you choose) installed and taught so you get **higher-quality output**, not random chat.  
3. **Skills** — structured prompting, verification habits that cut down wrong answers, and enough Linux/command-line comfort to work fast in a text interface when that wins.

You own the hardware. You own the data. We set it up, optimize it, and teach you to run it.
